# Tiny implementation controls

`scripts/make_synthetic.py` produces ten authored controls, two per planned task kind. `scripts/make_fixtures.py` produces corresponding authored generation request vectors; these are not transport captures. No corpus, human Gold, live quality, heldout experiment or model cost/latency result is established. Producers refuse to overwrite an output. Both outputs are canonical UTF-8 JSON and can be regenerated byte for byte from this source revision.
