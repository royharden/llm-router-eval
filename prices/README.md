# Synthetic unit prices

`synthetic-unit-v1.json` is an authored arithmetic fixture, not an OpenAI, TypeSafe or other provider price. Its names, rate and date are synthetic. No official URL, verified-primary time, source commit, API capability or access is claimed. Never use it as a live inference price/bound proof.

The pure update utility validates a caller-supplied snapshot's closed schema, content hash and provenance consistency before exclusively creating a new local file. Actual primary verification, effective dates, freshness and applicability require separate evidence and authorization.
