# Prompt-only routing source

`RouteInput(prompt_id, text)` is the only prompt data accepted by `Policy.route(item, context)`. `RouteInput.from_data_view` maps the data module's exact `task_id`/`prompt` projection and rejects extra fields. Policies cannot import scoring or reporting-reference modules. This is an allowlist within one trusted process, not process isolation.

Create a fresh `RouteContext` per item and policy. Explicit caller callbacks provide tier answers, generation and native typed judgments, returning validated `TierAnswer` or `ObservedResult` values with actual consumed span IDs. The caller owns real Provider/Ledger admission, execution, records and final-tier generation. Context caches a previously consumed tier answer, rejects changed item/reused context/duplicate span IDs, and retains all observed routing, check and cheap spans. A policy returns `RouteDecision(tier, reasons, confidence, consumed_span_ids, version)`. After final-tier execution the runner must include its spans too. Callbacks are not a transport or funding grant.

Six policy families expand to seven variants: `always_cheap`, `always_frontier`, `rules`, `classifier`, `jev_gate`, `cascade_jev`, `cascade_llm`. Baselines make no router call. Rules parse bounded code first, otherwise use a frozen UTF-8 length threshold, code fences and optional fixed keywords. Classifier generation uses a closed tier/confidence0..1 schema; invalid output selects frontier, and code-ineligible selection becomes cheap. Jev uses native Score criteria in their original order, preserves fractional0..3 output, and the consumer rounds ties upward/clamps the index. Low confidence bumps the mapped tier code -> cheap -> frontier; the top saturates.

The code tier accepts only complete ASCII prompts `Compute the sum of the integers: 1, 2, -3.` or `Compute the product of the integers: -2, 3, 4.` with 1–20 signed integers, each at most nine digits, at most512 UTF-8 bytes and result magnitude at most10^18. It computes actual prompt values and emits `FINAL: <integer>`. Unsupported text falls back; nothing executes as Python. The selected G plan's narrow integer handlers are the MVP. The alternative A plan's decimal/unit/date/string/base handlers are deferred.

Cascade consumes cheap first. A universal final-line formatting gate reads no hidden task kind, answer or rubric. Malformed output escalates without a checker. Valid output still escalates whenever there is no trusted matching validated calibration. No guessed threshold, confidence0.95 or constructor flag bypasses the gate. `CheckerCalibration` needs the separately trusted receipt plus matching `calibration_scope(context, backend)`, status, threshold0.5/0.7/0.9, >=40 dev responses, >=20 human-fail examples, >=20 accepts and false accepts/all accepts <=5%. The scope binds public configuration, models, backend, checker contract and instructions. The caller's public configuration hash must include actual provider/config, corpus/dev split and tuning dependencies; the later runner must construct and seal it from those inputs. Receipt hash membership is a trusted caller input, not independent validation of human labels. No real calibration is included.

With no permit, the executable cascade skips its checker and escalates every cheap response; later full-matrix collection may still collect experimental check observations separately. Validated Jev checking uses Noul, while generation checking uses a closed accept/probability object with coherent vote. Request data contains prompt/response plus generic correctness/completeness/relevance instructions only. Errors escalate while retaining observed spans.

`references` is reporting-only. Seeded random excludes unavailable code. The cheapest-passing oracle uses actual recorded costs, ignores ineligible code, and marks no-pass rows as failure at the least-cost eligible tier. Unknown costs stay unknown; no invented free tier or assumed price order is used. Neither reference is available from the executable policy context.

Current checks use authored synthetic callback results. There is no runner, calibrated quality result, live provider call or durable campaign acceptance. Python3.12/Pydantic core only; no SDK/image/embedding dependency is added here.
