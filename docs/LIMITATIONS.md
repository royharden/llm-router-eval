# Current limitations

The repository contains a keyless package, shared wire models and generated schemas.

- Router policies, scoring, durable ledger, executing adapters and evaluation are not implemented.
- No licensed 300-prompt corpus or human judge labels have been acquired.
- No cost, quality, savings or latency result is measured.
- Only the models closure is available for source-pinned consumer adoption; executing interfaces remain unavailable.
- No provider authentication, resource provisioning or public release is established.

Future implementations must generate named failures from actual evaluation output and preserve incomplete evidence honestly.

See [INTERFACE.md](INTERFACE.md) for model-only boundaries: declarations do not reserve money, calculate prices, validate actual image files or execute arbitrary generation-output schemas.
